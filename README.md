## 📂 Repository Structure <a name="structure"></a>

Problems are organized by difficulty level and grouped into folders.

```

codeforces/
├── A/
│   ├── Anton and Danik/
│   ├── Beautiful Matrix/
│   ├── Vanya and Fence/
│   ├── Bear and Big Brother/
│   └── Team/
├── README.md

```

Each folder contains:

- ✅ Problem solution (C++)
- ✅ Clean and readable implementation
- ✅ Optimized approach when applicable
